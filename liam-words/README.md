# Liam Words

Phone-first PWA prototype for toddler word practice (picture → say it → Auslan video).

## Open

- Local: open `index.html` (service worker needs HTTP(S)).
- Quick preview: [raw.githack](https://raw.githack.com/paulmichaelaxisa/GrokApps/main/liam-words/index.html)
- Phone: open that URL in Safari/Chrome, or Add to Home Screen.

## Words (v1)

mummy, daddy, milk, more, ball, dog, water, bye, eat, book, car, sleep

## Auslan note

**No in-app sign diagrams or invented tips.** The Auslan step only links to the official [Auslan Signbank](https://auslan.org.au/dictionary/) video for each word. Always confirm with Liam’s therapists / teachers of the deaf.

## Stack

Zero-build static HTML/CSS/JS · Web Speech API · PWA manifest + basic SW
